# FinCoreCms 小程序端操作手册

## 前提条件

- 微信开发者工具已安装
- 项目已导入（目录 `fin-core-miniapp`）
- `app.js` 中 `host` 已配置为本机 IP
- 「不校验合法域名」已开启

## 1. 登录

1. 打开小程序，输入用户名和密码
2. 点击「登录」
3. 登录成功后进入功能首页

## 2. 首页导航

首页展示 5 个功能入口卡片：
- 📋 **账单查询** — 查看账单列表
- 💳 **支付确认** — 扫码确认付款
- 📷 **扫码核销** — 扫描核销码
- ✅ **审批处理** — 待审批操作
- 📊 **报表摘要** — 关键数据卡片

## 3. 账单查询

点击首页「账单查询」→ 进入账单列表页
- 上拉加载更多
- 下拉刷新
- 点击任意账单 → 进入账单详情
- 详情页展示：账单编号、客户ID、周期、总额、已付、状态

## 4. 支付确认

点击首页「支付确认」

### 方式一：扫码支付
1. 点击「扫码支付」按钮
2. 扫描 PC 端生成的付款二维码
3. 自动查询付款信息
4. 确认金额后点击「确认支付」

### 方式二：手动输入
1. 输入付款 ID
2. 点击「查询」
3. 确认付款信息后点击「确认支付」

> ⚠️ 仅「待审批」或「审批中」的付款可支付，已处理显示提示信息

## 5. 扫码核销

点击首页「扫码核销」

### 扫码核销
1. 点击「扫描核销码」
2. 扫描 PC 端收款管理生成的核销二维码
3. 自动核销

### 手动输入
1. 输入核销码
2. 点击「核销」

核销成功后显示收款信息（编号、付款方、金额）

## 6. 审批处理

点击首页「审批处理」→ 进入待审批列表
- 每条记录显示：业务类型、业务ID、当前节点/总节点
- **通过**：弹窗确认 → 点击确认通过
- **驳回**：弹窗填写驳回原因 → 确认驳回

## 7. 报表摘要

点击首页「报表摘要」→ 三个 Tab 切换：
- **收支**：总收入、总支出、净流量卡片
- **余额**：当前余额、总流入、总流出、交易笔数
- **结算**：订单总数、已结算/已付款金额、待结算笔数

## 常见问题

| 问题 | 解决 |
|------|------|
| 请求失败 | 检查 PC 端服务是否启动、IP 配置正确 |
| 支付确认失败 | 确认付款状态为「待审批」、审批流未处理 |
| 扫码无反应 | 检查微信开发者工具扫码功能权限 |
