# FinCoreCms PC 端操作手册

## 1. 登录

1. 浏览器打开 `http://localhost:5173`
2. 输入用户名 `admin`，密码 `admin123`
3. 点击「登录」

## 2. 订单管理

### 2.1 新建订单
左侧菜单 → **订单结算** → **订单管理** → 点击「新建订单」
- 填写客户名称、合同号、订单金额
- 可添加订单明细（产品、数量、单价）
- 点击「保存」

### 2.2 批量计算费用
1. 勾选一个或多个状态为「待结算」的订单
2. 点击「批量计算费用」
3. 确认弹窗 → 系统按费率规则自动计算

### 2.3 导入/导出
- **导出 Excel**：点击「导出 Excel」→ 下载 CSV 文件
- **导入 Excel**：编辑 CSV → 点击「导入 Excel」上传

### 2.4 关闭订单
在订单列表操作列，点击「关闭」按钮（仅待结算状态可关闭）

## 3. 费率规则

左侧 → **订单结算** → **费率规则**
- **新建规则**：填写名称 → 选择类型（百分比/固定）→ 设置费率 → 保存
- **启用/禁用**：点击对应按钮切换
- 系统批量计算时使用所有「启用」的规则

## 4. 结算管理

左侧 → **订单结算** → **结算管理**

### 4.1 生成结算单
1. 点击「生成结算单」
2. 弹窗中选择已计算费用的订单（多选）
3. 填装备注 → 点击「生成」

### 4.2 确认/作废
- **确认**：结算单生成后，点击「确认」→ 订单状态变为「已结算」
- **作废**：点击「作废」→ 订单回退为「待结算」

## 5. 收款管理

左侧 → **收付款** → **收款管理**

### 5.1 新建收款记录
- 点击「新建收款记录」
- 填写付款方名称、金额、收款方式
- 保存

### 5.2 确认到账
在列表操作列点击「确认到账」→ 收款状态变为「已到账」

### 5.3 查看核销码
点击「核销码」可获取二维码供小程序扫码核销

### 5.4 搜索
按付款方名称、收款状态筛选

## 6. 付款管理

左侧 → **收付款** → **付款管理**

### 6.1 发起付款申请
- 点击「发起付款申请」
- 填写收款方名称、金额
- 可选：供应商ID、关联订单ID、备注
- 提交 → 自动生成审批流

### 6.2 审批付款
- 点击「审批通过」→ 付款完成
- 点击「驳回」→ 填写驳回原因 → 付款驳回

## 7. 账单管理

左侧 → **收付款** → **账单管理**

### 7.1 生成账单
- 点击「生成账单」
- 填写客户ID、账单周期、总额、已付金额
- 保存

### 7.2 合并账单
1. 勾选 2 个以上账单
2. 点击「合并账单」
3. 确认弹窗 → 生成新合并账单

### 7.3 拆分账单
1. 勾选 1 个账单
2. 点击「拆分账单」
3. 输入各笔金额（总和必须等于原账单）
4. 确认 → 生成多笔子账单

### 7.4 发送账单
点击「发送」按钮 → 标记为已发送

## 8. 审批管理

左侧 → **收付款** → **审批管理**
- 查看待审批列表
- 对每条记录可「通过」或「驳回」
- 审批完成后记录消失

## 9. 资金管理

### 9.1 银行账户
左侧 → **资金流水** → **银行账户**
- 新建账户：填写银行名称、账号、初始余额
- 编辑：修改账户信息

### 9.2 流水记录
左侧 → **资金流水** → **流水记录**
- **手动录入**：选择账户 → 选择收入/支出 → 填写金额、对方、摘要
- **银行同步**：选择账户 → 点击「银行同步」→ Mock 导入银行数据

### 9.3 对账管理
左侧 → **资金流水** → **对账管理**
- **执行对账**：选择账户、日期范围 → 自动匹配系统流水与银行流水
- **差异处理**：对金额不符的记录点「确认」或「忽略」

## 10. 报表

左侧 → **报表**
- **收支明细**：按日汇总收入/支出/净流量
- **资金余额**：当前总余额、流入/流出统计
- **结算统计**：订单总数、已结算金额、待结算金额
